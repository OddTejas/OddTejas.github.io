# OddTejas.github.io
My personal website:

## goals:
Blazing fast
Accessible
easy to navigate
use interior design philosphy
not cluttered but not minimalist.
high optimization

## Design principles
It should answer;
1. why this site exist
2. whose is it and about me
3. what i do(very short)
4. every new thing deserves it own page

## Things I won't do

- Autoplay videos.
- Hero videos.
- Unnecessary animations.
- Pages without a purpose.
- Widgets that don't add value.
- Copy trends for the sake of trends.
